# Emails (New)

API endpoints for managing emails created with the new Email Designer in Marketo Engage.

## Operations

| Method | Path | Operation |
|---|---|---|
| `POST` | `/rest/asset/v2/email` | [Create Email](create-email.md) |
| `POST` | `/rest/asset/v2/email/bulk/delete` | [Bulk Delete Emails](bulk-delete-emails.md) |
| `POST` | `/rest/asset/v2/email/bulk/get` | [Bulk Get Emails](bulk-get-emails.md) |
| `POST` | `/rest/asset/v2/email/bulk/usedby` | [Bulk Get Emails Used By](bulk-get-emails-used-by.md) |
| `POST` | `/rest/asset/v2/email/clone` | [Clone Email](clone-email.md) |
| `GET` | `/rest/asset/v2/email/filter` | [List Emails](list-emails.md) |
| `POST` | `/rest/asset/v2/email/state/transition` | [Update Email Status](update-email-status.md) |
| `POST` | `/rest/asset/v2/email/usedby` | [Get Email Used By](get-email-used-by.md) |
| `GET` | `/rest/asset/v2/email/{id}` | [Get Email by Id](get-email-by-id.md) |
| `POST` | `/rest/asset/v2/email/{id}/delete` | [Delete Email](delete-email.md) |
| `POST` | `/rest/asset/v2/email/{id}/update` | [Update Email](update-email.md) |
