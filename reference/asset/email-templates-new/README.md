# Email Templates (New)

API endpoints for managing email templates created with the new Email Designer in Marketo Engage.

## Operations

| Method | Path | Operation |
|---|---|---|
| `POST` | `/rest/asset/v2/emailtemplate` | [Create Email Template](create-email-template.md) |
| `POST` | `/rest/asset/v2/emailtemplate/bulk/delete` | [Bulk Delete Email Templates](bulk-delete-email-templates.md) |
| `POST` | `/rest/asset/v2/emailtemplate/bulk/get` | [Bulk Get Email Templates](bulk-get-email-templates.md) |
| `POST` | `/rest/asset/v2/emailtemplate/bulk/usedby` | [Bulk Get Email Templates Used By](bulk-get-email-templates-used-by.md) |
| `POST` | `/rest/asset/v2/emailtemplate/clone` | [Clone Email Template](clone-email-template.md) |
| `GET` | `/rest/asset/v2/emailtemplate/filter` | [List Email Templates](list-email-templates.md) |
| `POST` | `/rest/asset/v2/emailtemplate/state/transition` | [Update Email Template Status](update-email-template-status.md) |
| `POST` | `/rest/asset/v2/emailtemplate/usedby` | [Get Email Template Used By](get-email-template-used-by.md) |
| `GET` | `/rest/asset/v2/emailtemplate/{id}` | [Get Email Template by Id](get-email-template-by-id.md) |
| `POST` | `/rest/asset/v2/emailtemplate/{id}/delete` | [Delete Email Template](delete-email-template.md) |
| `POST` | `/rest/asset/v2/emailtemplate/{id}/update` | [Update Email Template](update-email-template.md) |
