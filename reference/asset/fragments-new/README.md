# Fragments (New)

API endpoints for managing fragments created with the new Email Designer in Marketo Engage.

## Operations

| Method | Path | Operation |
|---|---|---|
| `POST` | `/rest/asset/v2/fragment` | [Create Fragment](create-fragment.md) |
| `POST` | `/rest/asset/v2/fragment/bulk/delete` | [Bulk Delete Fragments](bulk-delete-fragments.md) |
| `POST` | `/rest/asset/v2/fragment/bulk/get` | [Bulk Get Fragments](bulk-get-fragments.md) |
| `POST` | `/rest/asset/v2/fragment/bulk/usedby` | [Bulk Get Fragments Used By](bulk-get-fragments-used-by.md) |
| `POST` | `/rest/asset/v2/fragment/clone` | [Clone Fragment](clone-fragment.md) |
| `GET` | `/rest/asset/v2/fragment/filter` | [List Fragments](list-fragments.md) |
| `POST` | `/rest/asset/v2/fragment/state/transition` | [Update Fragment Status](update-fragment-status.md) |
| `POST` | `/rest/asset/v2/fragment/usedby` | [Get Fragment Used By](get-fragment-used-by.md) |
| `GET` | `/rest/asset/v2/fragment/{id}` | [Get Fragment by Id](get-fragment-by-id.md) |
| `POST` | `/rest/asset/v2/fragment/{id}/delete` | [Delete Fragment](delete-fragment.md) |
| `POST` | `/rest/asset/v2/fragment/{id}/update` | [Update Fragment](update-fragment.md) |
