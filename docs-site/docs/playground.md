# Request Playground

Choose any operation to build a request, generate cURL, JavaScript and Python samples, and create
a schema-based mock response. The same builder appears on every operation page.

!!! note "Mock mode only"

    Nothing is sent to Marketo, and no credentials are requested or stored. Code samples use
    placeholders such as `<ACCESS_TOKEN>` that you replace in your own environment.
