# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:
[report a vulnerability](https://github.com/harrison-jennings/api-reference-for-marketo-engage/security/advisories/new).
Don't open a public issue.

Include a description of the problem, the steps to reproduce it and the affected page or file. This
is a personal project, so there is no guaranteed response time, but every report is read.

## Scope

In scope:

- the documentation site at <https://mkto-ref.harrisonjennings.au/>, including the Request Builder
- the Postman collection and environment template in `postman/`, including the script on the
  collection's Identity requests
- the reference generator and other scripts in this repository
- this repository's GitHub Actions workflows

Adobe Marketo Engage and its APIs are out of scope. Report vulnerabilities in them to Adobe through
[Adobe's security reporting process](https://helpx.adobe.com/security/alertus.html).
